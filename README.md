# 🧠 DeepSeek Memory

**Modified DeepSeek AI with long‑term memory.**

A private, password‑protected AI assistant built on Groq, with persistent chat history, code block support, and built‑in guardrails.

## ✨ Features
- 🧠 Long‑term memory (in‑memory with context retrieval)
- 🔐 Multi‑password authentication
- 💬 Chat history saved in localStorage
- 📋 Copyable code blocks with language labels
- 🛡️ Built‑in safety guardrails
- 🚀 Deployed on Render + GitHub Pages

## 🛠️ Tech Stack
- **Backend:** Node.js + Express
- **LLM:** Groq (Llama 3.3 70B) with multi‑key rotation
- **Frontend:** Vanilla HTML/CSS/JS
- **Deployment:** Render (backend) + GitHub Pages (frontend)


## Is DeepSeek Personal Paid?

No. DeepSeek Personal itself is free to use. However, if you choose to fork or deploy your own personal instance, hosting and infrastructure costs may apply depending on the platform or resources you use.
