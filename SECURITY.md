# Security Policy

## Supported Versions

We actively support the currently released versions of DeepSeek-Personal. Security updates and patches are provided for supported releases as needed.

| Version | Supported |
| ------- | --------- |
| 5.1.x   | Not yet released |
| 5.0.x   | Not yet released |
| 4.0.x   | Not yet released |
| 1.0.x    | ✅ Supported |

## Reporting a Vulnerability

If you discover a potential security vulnerability within DeepSeek-Personal, please report it by opening a GitHub issue.

When reporting a vulnerability, please include:
- A clear description of the issue
- Steps to reproduce the vulnerability
- Any relevant logs, screenshots, or proof of concept details
- The potential impact of the issue

We appreciate responsible disclosure and will review all security reports as quickly as possible.

## Security Updates

This policy will be updated as DeepSeek-Personal evolves and new security improvements are introduced.

Security fixes, improvements, and important changes will be included in future releases.

## Code Review & Security Auditing

Yes, DeepSeek-Personal has a dedicated team that reviews the codebase for security concerns.

The security review team:
- Reviews code during every major update
- Identifies potential vulnerabilities and security risks
- Does not have permission to directly modify the codebase
- Provides feedback and reports to the development team for review

Security reviews are performed whenever updates are made to help maintain the safety, stability, and reliability of DeepSeek-Personal.
